# DermaCare

Учебное мобильное приложение для записи к дерматологам. Expo (SDK 58), React Native, Expo Router, TypeScript. Языки: русский и казахский.

## Запуск

    npm install
    npx expo start

Отсканируй QR-код в Expo Go.

Проверки:

    npx tsc --noEmit
    npx expo lint

## Демо-аккаунт

Почта `demo@dermacare.kz`, пароль `123456`. Новые аккаунты хранятся только в памяти.

## Структура src

- `app` экраны и навигация (`(auth)` вход, регистрация, новый пароль; `(tabs)` главная, чат, профиль, календарь)
- `components` повторяющиеся компоненты
- `context` состояние: язык, пользователь, избранное, врачи
- `i18n` словари ru и kk (единственная папка сверх Food-Delivery: нужна для двух языков)
- `theme` цвета, шрифты, отступы
- `utils` проверка форм, форматирование, фильтры, расписание
- `data` локальные данные: врачи, приёмы
- `api` загрузка списка врачей
- `illustrations` SVG: логотип, иконки, аватары

`server/doctors.json` список врачей для публикации на GitHub.

## API врачей

Пока `src/api/config.ts` пустой, врачи берутся из `server/doctors.json` внутри приложения. Чтобы грузить по сети, выложи файл на GitHub, возьми raw-ссылку и вставь в `DOCTORS_URL`.

## Имитация

Вход через Google, Facebook, отпечаток пальца, чат, уведомления. Расписание и рейтинги врачей демонстрационные.
